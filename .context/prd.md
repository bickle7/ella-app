# Ella's Daily Checklist App — PRD

## What is it?
A fun, visual iPad app for a 6/7 year old to work through her daily tasks independently. Big, bright, and child-friendly — designed to be used by her but managed by both parent and child.

## Target User
6 year old girl (Ella), using on iPad

## Morning Routine Tasks
- Wake up
- Have a wee
- Feed Furry (guinea pig)
- Make bed
- Put teddies on bed
- Have breakfast
- Brush teeth
- Get knickers and socks
- Get dressed
- Brush hair
- Put PJs on bed
- Get bags ready (put on sofa)
- Shoes on
- Coat on

## Core Features
- Display day and date prominently on screen
- Active Monday—Friday only (weekends off)
- Ability to skip a day (holidays, sick days)
- Tasks reset automatically every morning
- Both parent and child can add/edit tasks
- Celebrations when tasks completed (confetti/animations, sounds, points/stars)

## Design Principles
- Big, bold, visual interface
- Child friendly — bright colours, large buttons
- Simple enough for a 6 year old to use independently

## Future Scope
- Multiple list types beyond morning routine
- Additional daily lists (bedtime routine, after school etc.)
